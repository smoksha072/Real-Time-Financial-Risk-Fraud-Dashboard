# Real-Time-Financial-Risk-Fraud-Dashboard

Built a one-page Power BI dashboard to simulate a unified risk monitoring system. The project analyzes fraud patterns, risk segmentation, and detection performance using transaction-level data.

-- Key Insights:
1. Fraud is highly concentrated in TRANSFER and CASH_OUT transactions
2. Fraud represents a very small portion (~0.13%), making detection challenging
3. Rule-based detection systems miss a significant number of fraudulent transactions
4. High-value transactions are more likely to be risky
